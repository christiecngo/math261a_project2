# Limited Explanatory Power Between Election Margin of Victory and Demographic Information Using Multiple Linear Regression
Date of submission: 12/10/2025

An exploratory investigation on the relationship between a United States congress official and their own characteristics as well as those of their constituents

## Data 

**Example statement:** Data used in this project is obtained from [HARVARD Dataverse](https://dataverse.harvard.edu) who provide the data under the [Creative Commons Public Domain Dedication and License](https://creativecommons.org/publicdomain/zero/1.0/).

## Organization

The "Code" subfolder contains the Quarto file (that generated the report), references.bib, and full R script of code.

"Data" contains the CSV file of Congress official information from Kimberly Martin’s aggregated dataset used in "Fairness in Women's Sports? Explaining State Legislator Support for Transgender Athlete Bans."

"Report" contains the full PDF output.
